The opposition

Shiba believes Kunishige’s eyes are the only way. Mashiro is still opposed to stealing ore for a civilian. Both can be true in the same bureau week. Hasumi’s lab is failing. The Sorcery Bureau is becoming an army. Irishima’s vein is already a national project. The partner’s no is printed so the kiln does not look like consensus.

Mashiro is alive in the talks. That matters. Part 2 is not only Chiaki and Kunishige in a fire. It is a table of people who remember the theft argument. Shiba will later leave the Kamunabi. Mashiro’s file stays bureau-shaped.

The later uncle
